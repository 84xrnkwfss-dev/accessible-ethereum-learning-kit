# Project Plan

## Problem

Ethereum node setup guides can be difficult for beginners and people who need clear, accessible instructions.

## Audience

- Beginners learning Ethereum
- Neurodiverse students
- Windows and PowerShell users
- Teachers running safe blockchain demonstrations

## Solution

A free step-by-step kit for creating a private Geth learning network, making transactions through JSON-RPC and viewing them in Blockscout.

## Planned deliverables

1. Safe Windows setup guide
2. Private Geth network scripts
3. Test-account and transaction examples
4. Blockscout setup guide
5. Accessibility notes and troubleshooting
6. Clear warnings separating test ETH from real ETH

## Public benefit

The project will be open source and free to use, change and share.
