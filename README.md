# Accessible Ethereum Learning Kit

A free, open-source Windows learning kit for beginners and neurodiverse students.

## Users will learn to

- Create a private Geth learning network
- Use prefunded test ETH
- Make safe test transactions
- Use Ethereum JSON-RPC
- View transactions with Blockscout

## Important

The test ETH exists only on the private learning network. It has no real monetary value.
